# Deploying SmartPOS

Two parts:

1. **Backend + database on Render.** Render auto-deploys from this GitHub repo.
2. **Frontend on Vercel.** Vercel auto-deploys from the `SmartPOS-frontend` repo.

Do the backend first, because the frontend needs its URL.

---

## Part 1: Backend on Render

Render has no built-in PHP runtime, so the repo includes a `Dockerfile` as the build recipe. **You never run Docker yourself.** Render reads the Dockerfile from GitHub and builds on its own servers.

### Steps

1. Sign in at <https://dashboard.render.com> with GitHub.
2. Click **New → Blueprint**.
3. Pick the repo `mraaron250-art/SmartPOS-backend` and branch `main`.
4. Render reads `render.yaml` and shows two resources:
   - `smartpos-backend` (web service, Docker, free plan)
   - `smartpos-db` (PostgreSQL 17, free plan)
5. Render asks for `CORS_ORIGINS`. Enter your Vercel URL, e.g. `https://smartpos-frontend.vercel.app`. If you don't know it yet, enter `http://localhost:3000` and change it later.
6. Click **Apply**. The first build takes about 3–5 minutes.
7. When the service is **Live**, open `https://<your-service>.onrender.com/api/health`. Expect:

   ```json
   { "status": "healthy", "database": "connected (PostgreSQL)", ... }
   ```

On every container start, the service:

- runs `php bin/console migrate` (applies new migrations only), then
- runs `php bin/console seed --if-empty` (loads the demo data only when there are no users yet).

`JWT_SECRET` is generated by Render. `DATABASE_URL` is linked from the database automatically.

### Environment variables

| Key | Set by | Notes |
| :--- | :--- | :--- |
| `DATABASE_URL` | render.yaml (from DB) | Internal connection string |
| `JWT_SECRET` | render.yaml (generated) | Rotating it logs everyone out |
| `CORS_ORIGINS` | You | Comma-separated frontend URLs |
| `APP_ENV` / `APP_DEBUG` / `APP_TIMEZONE` | render.yaml | `production` / `false` / `Asia/Manila` |

### Free plan limits

- The web service sleeps after 15 minutes idle. The next request takes about 30–60 seconds to wake it.
- **Free PostgreSQL expires 30 days after creation.** Upgrade the database plan before then, or the data is deleted.

## Part 2: Frontend on Vercel

1. Sign in at <https://vercel.com> with GitHub.
2. Click **Add New → Project** and import `mraaron250-art/SmartPOS-frontend`.
3. Framework preset: **Next.js** (auto-detected).
4. Under **Environment Variables**, add:

   | Key | Value |
   | :--- | :--- |
   | `BACKEND_URL` | `https://<your-service>.onrender.com` (no trailing slash) |

5. Click **Deploy**.
6. Copy the Vercel URL. Then go back to Render → `smartpos-backend` → **Environment** and set `CORS_ORIGINS` to that URL.

---

## Smoke test after deploy

1. `GET https://<render>/api/health` returns `healthy`.
2. Open the Vercel URL. Log in as `owner@smartpos.local` / `password123`.
3. Ring up a sale in POS. Check that stock goes down in Inventory.
4. Log in as `staff@smartpos.local` and confirm that Users and Reports are restricted.
5. **Change the demo passwords.**

## Local development

```bash
# Backend (http://localhost:8000)
cd SmartPOS-backend
docker compose up --build

# Frontend (http://localhost:3000)
cd SmartPOS-frontend
echo "BACKEND_URL=http://localhost:8000" > .env.local
npm install && npm run dev
```

Reset the local database:

```bash
docker compose exec api php bin/console fresh --seed
```
